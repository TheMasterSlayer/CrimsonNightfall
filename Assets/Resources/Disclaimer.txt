CrimsonNightfall contains flashing lights, loud sounds, sudden audio, and horror imagery.

Photosensitive players and players sensitive to frightening content should use discretion.

Developer note to players:
This is my first personal videogame creation project, and I've made sure to thoroughly test it so that there aren't any game
breaking features present within gameplay. Personally as a gamer, I do try to find bugs in games, so I would expect some of you to 
try and do the same. If you had a fun experience or found anything from a simple to a crazy bug, please let me know within the 
inquiry box below and I'll make sure to read everything that is sent.

Lastly, there is only so much playtesting that can be done with the "Chaos" mode. It is clear that objects will fly, shift, and
ultimately be displaced from their current position, potentially making a gameplay impossible. This gamemode is only for those who
enjoy a crazy challenge and maybe found "Normal" mode to be too easy.

There are a few easter eggs in the game, ranging from just pure interactables and fun item usage, so if you like easter eggs,
make sure to be on the search for them.
